# Visual direction

Keep the established quiet native messenger style. A numbered three-step sequence
communicates real setup order; symbols identify the computer, network and account.
The guide has one primary Continue action and optional technical disclosures.
Use semantic primary/secondary text, native grouped surfaces, Dynamic Type titles
and 44-point minimum action heights. No new palette, typeface, animation or glass.

Compact: title → step count / heading → grouped instructions → Continue.
Regular: the same Form in the system sheet; it remains scrollable and dismissible.
Largest Dynamic Type: prose wraps, sections grow vertically, all actions scroll.

Apple references: `onboarding.md` → Best practices (optional and available later),
`entering-data.md` → Best practices (dynamic validation), `layout.md` → Visual
hierarchy (progressive disclosure), `accessibility.md` → Vision / Mobility
(semantic sizing and labeled controls). swiftui-pro navigation and accessibility
references informed the sheet, toolbar and text choices.
